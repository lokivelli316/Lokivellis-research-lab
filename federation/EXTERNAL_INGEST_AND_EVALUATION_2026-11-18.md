# External Ingest and Evaluation Federation — 2026-11-18

This is an additive federation note for Lokivelli's Research Lab. It does not replace the existing donor register, THROAT/GARGANTUA surfaces, Bulk Interference / Throat Coupling v0.2 program, Deep Research packets, receipts, or publication gates.

## Candidate pipeline

`download-anything -> lemmeknow -> md-anything -> staged corpus -> Research Lab provenance/receipts -> analysis`

- **download-anything**: candidate acquisition layer for public research inputs. Downloads must land in a staging area with source URL and verification evidence retained.
- **lemmeknow**: candidate preflight classifier for unknown strings/files before routing.
- **md-anything**: candidate normalization layer for documents/media into agent-readable text/structured output. The normalized derivative never supersedes the original source.
- **uv**: candidate isolated Python dependency/tool substrate for research utilities after Termux/target-runtime verification.
- **NVIDIA SkillEvaluator**: candidate gate for any Agent Skills added to the research workflow; INCOMPLETE must remain INCOMPLETE when required checks cannot execute.
- **CLI-Anything**: candidate adapter factory when an existing scientific application needs a structured CLI rather than a rewrite.
- **rust-anything**: candidate optimization/migration tool only for computational hot paths where behavior can be recorded and replayed. Run against copies/test data; no scientific conclusion is promoted merely because an implementation is faster.
- **awesome-mcp-servers**: discovery catalog for possible research connectors. Catalog presence is not adoption.

## Authority boundary

Research Lab continues to own theory, derivations, matrices/tensors, observations, launch surfaces, Deep Research packets, receipts, and publication packaging. Millennial Dragon Ball remains an independent federated adversarial engine. External tooling may transport, classify, normalize, wrap, or evaluate inputs and skills; it does not promote UNKNOWN/HOLD evidence to PASS and does not convert a research build into scientific validation.

## Publication boundary

Every externally acquired or normalized source should retain, at minimum: original locator, acquisition timestamp, content hash where available, tool/version used, derivative path, and any verification limitation. A normalized Markdown or transcript derivative is evidence about a source, not the source itself.
