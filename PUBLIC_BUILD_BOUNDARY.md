# Public Build Boundary

This repository is the **public, keyless Research Lab build**.

The private execution build lives separately and may contain provider-specific Titan routing, private donor federation, and runtime secret slots. This public repository does not contain credential values and does not require private API keys to launch its core surfaces.

## Public build includes

- deterministic laboratory interfaces and schemas;
- derivation ledgers and scientific-status boundaries;
- matrix/tensor attack specifications;
- public or publication-authorized visualization donors;
- public dataset adapters and provenance;
- receipts and reproducibility artifacts;
- keyless fixtures/mocks for model-routing interfaces where needed;
- Zenodo publication package.

## Public build excludes

- raw API keys or tokens;
- private donor source not authorized for publication;
- secret-bearing logs;
- private provider account state;
- private Titan runtime configuration containing credentials.

## Federation contract

The private build may export validated, sanitized artifacts into this repository. Export is one-way and receipt-bound. The public repository never requires access to the private repository to reproduce its public scientific artifacts.
