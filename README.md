# Lokivelli's Research Lab

Federated physics research stack and publication lane.

## Current build lane

The active experimental program is **Bulk Interference / Throat Coupling v0.2**. It preserves the frozen v0.1 conceptual structure while repairing derivations before any post-hoc observational fitting.

### Architecture

- **Research Lab owns** theory, derivations, matrices/tensors, observations, launch surfaces, Deep Research packets, receipts, and publication packaging.
- **Millennial Dragon Ball remains independent** and is consumed as a federated adversarial engine. It is not absorbed into this repository.
- **GARGANTUA / THROAT** is preserved as the scientific visualization and navigation surface. The recovered standalone donors are kept intact under `apps/`.
- **Private experimental repositories** are donors. They are registered with provenance and confidence instead of merged indiscriminately.
- Every empirical or mathematical promotion requires receipts. UNKNOWN does not become PASS.
