# Causal / Correlation Adversarial Matrix

Status: **MANDATORY CONTINUOUS ATTACK LAYER — additive to D1–D10.**

This layer does not replace the derivation ledger, matrix/tensor attack, ordinary astrophysics, bulk hypotheses, or null models. It runs beside them from intake through publication.

## Governing rule

Every positive-looking fit must immediately spawn its negative mirror and its strongest surviving alternative.

Never ask only:

```text
Does this fit?
```

Always ask, in the same pass:

```text
What exactly fits?
Who else fits?
Who should fit but does not?
Who should not fit but does?
What fits better?
What common cause can create both?
What ordinary mechanism can create the same signature?
What happens when the condition is inverted?
What happens when labels are hidden and the frozen model ranks the population blindly?
What assumption are we not asking because everybody already accepted it?
```

## Parallel causal lanes

Do not force ordinary physics and bulk physics into an unnecessary either/or.

```text
H0  = ordinary astrophysics + coincidence/systematics
H1  = ordinary 3+1 propagation
H2  = bulk interference + throat coupling
H3  = ordinary + bulk additive
H4  = ordinary × bulk interaction / susceptibility coupling
HCC = common-cause model
HS  = selection / measurement / cadence / pipeline systematic
HA  = linear bulk interference
HB  = geometric focusing / caustics
HC  = nonlinear buildup + throat discharge/backfire
```

For receiver event E, local state X and predicted bulk condition Ψ, explicitly compare:

```text
P(E | X)
P(E | Ψ, X)
P(E | ¬Ψ, X)
P(¬E | Ψ, X)
P(¬E | ¬Ψ, X)
P(Ψ | E)        !=        P(E | Ψ)
```

The distinction between `P(Ψ | E)` and `P(E | Ψ)` is mandatory.

## Causal-stage matrix

No stage silently promotes into the next.

| Stage | Question | Minimum evidence | Failure / HOLD trigger |
|---|---|---|---|
| Correlation | Do variables co-vary beyond null expectations? | effect size + uncertainty + base rate + controls | look-elsewhere / confounder / unstable effect |
| Temporal order | Does the proposed cause precede the response after all delays are separated? | frozen timing law + uncertainty budget | receiver transition precedes cause |
| Propagation | Can the influence physically travel between nodes? | derived operator / speed / path / boundary conditions | no allowed mode/path |
| Convergence / interference | Do multiple contributions combine as claimed? | derived phase/coherence law | random phases erase required cross terms |
| Coupling | Can the bulk state act on the receiver? | explicit `C_throat` / transfer law | units/sign/conservation/causality fail |
| Trigger / susceptibility | Can the receiver state alter response probability? | independently defined `X_receiver` | effect disappears after receiver-state control |
| Mechanism | Is every arrow physically specified? | source→propagation→coupling→receiver→observable | missing arrow |
| Causal discrimination | Does the proposed model beat strongest alternatives? | model comparison + negative controls + ablations | ordinary/common-cause model performs equally well |
| Prospective prediction | Does a frozen model predict unseen data? | preregistration + holdout/future sample | coefficients/rules moved after exposure |

## 2×2 negative-space matrix

Every event test must report the complete confusion structure.

| | Event E | No event ¬E |
|---|---:|---:|
| Predicted condition Ψ | TP | FP |
| No predicted condition ¬Ψ | FN | TN |

Required derived quantities when data permit:

```text
sensitivity / recall
specificity
precision / positive predictive value
negative predictive value
false-positive rate
false-negative rate
base event rate
likelihood ratios

```

A spectacular TP count is not meaningful without FP, FN and TN.

## Positive twin / negative twin search

For every highlighted target:

### Positive twin
Find the strongest other objects/events that satisfy the same frozen criteria.

Ask:
- who else fits equally well?
- who fits better?
- is the target merely one member of a broad ordinary class?
- does the effect survive removal of the originally interesting target?

### Negative twin
Find the closest controls that match the target on ordinary covariates but do not show the predicted outcome.

Ask:
- what variable actually separates them?
- is that separator a model variable or an ordinary confounder?
- does receiver susceptibility explain the split prospectively?

### Nearest false positive
Find the object least expected to respond that nevertheless receives a high model score.

### Nearest false negative
Find the object expected to respond strongly that does not.

Neither is discarded. Both become attack coordinates.

## Blind retrieval test

Before revealing labels or target status:

```text
frozen model
→ complete candidate population
→ score every object/event
→ rank
→ reveal labels afterward
```

Record:
- target rank;
- percentile;
- number of non-targets ranked above it;
- model parameters frozen before ranking;
- all exclusions and their reasons.

If the event looks special only after its identity is supplied, mark **POST-HOC / HOLD**.

## Common-cause matrix

For every A↔B correlation test:

```text
A → B
B → A
C → A and C → B
A ← C → B
A and B both produced by pipeline/selection S
A and B independent after conditioning on X
```

The common-cause lane is never removed merely because the direct-causation lane is interesting.

## Receiver susceptibility matrix

The same field need not produce the same outcome in every receiver.

For each receiver class r define or constrain:

```text
R_r[Ψ, X_r, history, phase]
P(E_r | Ψ, X_r)
P(E_r | ¬Ψ, X_r)
```

Compare at minimum the existing observation classes:

```text
Sun/heliosphere
main-sequence stars
white dwarfs
pulsars
magnetars
FRBs
AGN/jets
SNe/threshold systems
galaxy redshift residuals
```

A model that claims receiver specificity must predict both responders and non-responders.

## Anti-cherry-pick question spine

Run these questions at derivation, simulation, event intake, correlation, interpretation and promotion stages:

1. What are all plausible causal lanes?
2. What does each lane predict before this result is inspected?
3. What is correlation, temporal order, mechanism and causation here?
4. Can ordinary and bulk causes both be real simultaneously?
5. What common cause can generate both sides?
6. What mechanism physically connects every arrow?
7. What happens when each component is removed?
8. What would kill or embarrass each interpretation?
9. Was this target chosen because it already looked interesting?
10. What denominator or base rate are we ignoring?
11. Are we testing receiver susceptibility or merely selecting dramatic events?
12. Could the same data support a different mechanism?
13. What entered the model before versus after observation?
14. Which uncertainties can flip the conclusion rather than merely widen it?
15. Does the chain conserve what it must conserve and remain dimensionally consistent?
16. What survives time/sky/phase/receiver permutations and nuisance regression?
17. Is the prediction specific enough to distinguish models?
18. Who else fits?
19. Who should fit but does not?
20. Who should not fit but does?
21. What is the nearest counterexample?
22. What is the nearest false positive?
23. What happens when the hypothesis is inverted?
24. If labels are hidden, where does the target rank?
25. What assumption is invisible because we accepted it without testing it?
26. **What the hell did we not ask that we should have asked already?**

## Strongest-alternative rule

Every explanation is compared against the strongest surviving alternative, not the weakest version of the alternative.

A result that fits H2 must still be tested against the best available H0/H1/H3/H4/HCC/HS implementation.

## Promotion rule

No result becomes SUPPORT because:
- it is spectacular;
- it matches after parameter adjustment;
- a target was selected retrospectively;
- only true positives were counted;
- negative controls were not searched;
- the ordinary side was removed;
- the bulk side was removed;
- a common-cause model was not tested;
- post-hoc and prospective evidence were mixed.

The output must retain the full matrix, including ugly cells.
